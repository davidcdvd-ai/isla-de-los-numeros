# La isla de los números

Juego educativo para aprender sumas, restas, multiplicaciones y repartos (de 5 a 12 años).

- Todo en un único `index.html`, sin dependencias externas ni servidor.
- Perfiles locales: el progreso se guarda solo en el navegador de cada dispositivo.
- Dificultad adaptativa por operación y explicaciones paso a paso cuando hay errores.
- Los animales de Kiko: cada misión trae un huevo o comida; para que crezcan hay que prepararles la cantidad justa con la operación de su zona (12 animales que coleccionar).

Para jugar, abre `index.html` en el navegador o visita la página de GitHub Pages del repositorio.
